# Ahmed Ramadan — Engineering Portfolio

A responsive, static professional portfolio for Ahmed Ramadan, Mechatronics Engineer and Senior Technical Sales Engineer – Pumping Systems.

## Deployment

- Platform: GitHub Pages
- Publishing source: `main` branch, repository root
- Build step: none
- Runtime dependencies: none
- Entry point: `index.html`

## Structure

- `index.html` — semantic page structure, portfolio content, SEO metadata and Person structured data
- `assets/site.css` — responsive visual system and layouts
- `assets/site.js` — accessible mobile navigation and project category filters
- `assets/favicon.svg` — vector favicon
- `robots.txt` and `sitemap.xml` — crawl guidance

## Content policy

Project entries describe the stated project context and Ahmed's documented involvement separately. Tender-stage and unverified CRM opportunities are excluded from the public portfolio. Commercial order values, private contact details, confidential correspondence and unapproved project photographs are not included.

## Local preview

Open `index.html` directly in a browser. No package installation or build process is required.

## Maintenance

Keep the site static and dependency-free unless a documented requirement justifies a change. Update the canonical URL and sitemap if the production domain changes.
